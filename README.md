📊 Hệ Thống Phân Tích Đồ Thị - Nhóm 7 (UTH)
Chào mừng bạn đến với dự án Hệ Thống Phân Tích Đồ Thị được thực hiện bởi Nhóm 7. Đây là một ứng dụng Python mạnh mẽ, hỗ trợ biểu diễn và thực thi các thuật toán lý thuyết đồ thị kinh điển với giao diện trực quan sinh động.

🌟 Tính năng chính
Ứng dụng cung cấp một bộ công cụ toàn diện để xử lý các bài toán đồ thị từ cơ bản đến nâng cao:

Quản lý đồ thị: Hỗ trợ cả đồ thị có hướng và vô hướng, nhập dữ liệu linh hoạt theo định dạng cạnh (u, v, w).

Chuyển đổi biểu diễn: Tự động chuyển đổi giữa danh sách cạnh và ma trận kề.

Thuật toán tìm kiếm & Duyệt: Triển khai BFS (Breadth-First Search) và DFS (Depth-First Search).

Đường đi ngắn nhất: Tìm đường đi tối ưu bằng thuật toán Dijkstra.

Cây bao trùm tối thiểu (MST): Tích hợp cả hai thuật toán Kruskal và Prim kèm minh họa trực quan.

Luồng cực đại: Tính toán luồng tối đa trong mạng bằng thuật toán Ford-Fulkerson.

Đường đi & Chu trình Euler: Hỗ trợ thuật toán Fleury và Hierholzer.

Kiểm tra tính chất: Xác định đồ thị có phải là đồ thị hai phía (Bipartite) hay không.

Trực quan hóa: Hiển thị cấu trúc đồ thị ngay trên giao diện bằng sơ đồ động.

🛠 Công nghệ sử dụng
Dự án được xây dựng trên nền tảng Python với các thư viện chuyên dụng:

Tkinter: Xây dựng giao diện người dùng (GUI).

NetworkX: Xử lý và tính toán các cấu trúc dữ liệu đồ thị phức tạp.

Matplotlib: Vẽ và trực quan hóa sơ đồ đồ thị.

NumPy: Hỗ trợ tính toán ma trận kề hiệu quả.

🚀 Hướng dẫn cài đặt
Để chạy ứng dụng trên máy cá nhân, bạn cần cài đặt các thư viện phụ thuộc:

Bash
pip install networkx matplotlib numpy
Sau khi cài đặt xong, bạn chỉ cần chạy file script chính:

Bash
python "Bai Tap Thi Ck Nhom 7.py"
📖 Cách sử dụng
Nhập liệu: Nhập danh sách các cạnh vào khung văn bản theo định dạng: Nguồn, Đích, Trọng số (Ví dụ: A, B, 5).

Vẽ đồ thị: Nhấn nút "VẼ ĐỒ THỊ TRỰC QUAN" để xem cấu trúc sơ đồ.

Thực thi: Chọn thuật toán cần chạy trong menu, nhập đỉnh bắt đầu và nhấn "CHẠY & TRỰC QUAN HÓA".

Báo cáo: Kết quả chi tiết sẽ hiển thị ở khung Log phía dưới, bạn có thể xuất kết quả ra file .txt.
